# cspell-dict

Directory for spell checker dictionary files

We use [cspell](https://github.com/streetsidesoftware/cspell) as our spell checker.

## Usage

For dictionary definitions, please refer to [Custom Dictionaries | CSpell](https://cspell.org/docs/dictionaries/custom-dictionaries/).

To use dictionaries in the repository, you need to register custom dictionaries in the cspell configuration file.

Please modify [cspell.config.yaml](../cspell.config.yaml) to use it.

For configuration file syntax, please refer to [Configuration | CSpell](https://cspell.org/configuration/).
